# Chain Sentinel — Protocol & Product Roadmap

The long-term vision for Chain Sentinel is to become the universal autonomous security and defensive liquidity infrastructure for Web3 treasuries, institutional funds, and decentralized protocols.

---

## Phase 1: Hackathon Release (Current // Q1 2026)
- [x] **ADK-TS Multi-Agent Engine**: Modular perception, planning, and governance agents built with `@iqai/adk`.
- [x] **LiquidShield Aave V3 Surveillance**: Continuous health factor monitoring and distance-to-liquidation calculation.
- [x] **WhaleWatch Mempool Listener**: Tracking large transactions exceeding $500,000 USD via Alchemy streams.
- [x] **Alert Correlator Pipeline**: Cross-agent threat discovery generating high-urgency compound alerts.
- [x] **ATP Registration**: Agent Tokenization Platform deployment manifest and `cSNT` token model.
- [x] **Neo-Brutalist Operations Dashboard**: Next.js 16 real-time monitoring interface with interactive hover-reveals.

---

## Phase 2: Cross-Chain Expansion & Flash Loan Hedging (Q2 2026)
- [ ] **Arbitrum & Base Native Deployments**: Zero-latency L2 mempool surveillance via sequencer feeds.
- [ ] **Cross-Chain Rebalancing via Chainlink CCIP**: Automatically transfer collateral from idle reserves on Base or Optimism to defend an at-risk position on Ethereum Mainnet.
- [ ] **Flash-Repay Integration**: Atomic flash-loan debt repayment circuits enabling treasuries to deleverage without holding immediate liquid capital.
- [ ] **Uniswap V3 Concentrated Liquidity Rebalancing**: Autonomous position widening during extreme volatility spikes.

---

## Phase 3: Zero-Knowledge Solvency & Institutional Multi-Sig (Q3 2026)
- [ ] **ZK-Solvency Proofs**: Generate zero-knowledge proofs confirming treasury capital adequacy without disclosing proprietary asset allocations.
- [ ] **Safe Multisig Automated Transaction Module**: Safe (Gnosis) Zodiac guard module that allows Chain Sentinel agents to execute pre-authorized defensive debt repayments while preventing unauthorized capital transfers.
- [ ] **On-Chain Oracle Manipulation Defenses**: Multi-block TWAP smoothing and outlier filtering to resist flash-loan oracle attacks.

---

## Phase 4: Decentralized Sentinel Mesh & DAO Governance (Q4 2026)
- [ ] **Decentralized Agent Mesh on ATP**: Multi-party decentralized verification of risk signals across independent Sentinel node operators.
- [ ] **Slashing & Staking Mechanics**: Node operators stake `cSNT` to validate alerts; fraudulent or malicious alerts are slashed.
- [ ] **Institutional DAO Risk As a Service**: Plug-and-play SDK for DAO treasuries (MakerDAO, Arbitrum DAO, Uniswap Foundation) to embed 24/7 automated risk containment.
