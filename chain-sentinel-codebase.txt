## 1. The Mission: Prevent Loss, Do Not React To It

Decentralized Finance operates at block speed. When lending collateral devalues or a whale triggers a multi-million-dollar cascade, human operational response is fundamentally too slow. By the time a risk manager receives a manual notification, the collateral is already liquidated.

Chain Sentinel introduces an autonomous, preventive defense layer:
- WhaleWatch Mempool Radar: Intercepts transactions exceeding $500,000 USD before block inclusion and classifies intent (Accumulation, Distribution, CEX Deposit).
- LiquidShield Aave V3 Engine: Continuous on-chain health factor monitoring with distance-to-liquidation analytics and automated partial debt repayment calculations.
- Cross-Agent Threat Correlator: Discovers compound risks when whale dumps intersect with at-risk lending positions within a sliding window.
- ADK-TS Multi-Agent Consensus: Specialized autonomous agents built with @iqai/adk (Watcher, Risk, Planner, Governance) backed by deterministic safety vetoes.
- ATP Tokenized Security Quotas: Registered with the Agent Tokenization Platform (cSNT) for verifiable autonomous execution.
- Neo-Brutalist Operations Matrix: High-contrast, rigid-grid Next.js 16 dashboard featuring oversized Cabinet Grotesk typography, zero-blur hard shadows, and interactive hover-reveals.

### 4.1 Prerequisites
- Node.js: 24.x

### 4.2 Installation
```bash
# Clone the repository
git clone https://github.com/vismaygawai/chain.sentinel.git
cd chain.sentinel

# Install workspace dependencies
pnpm install
```

### 4.3 Environment Setup
```bash
cp .env.example .env
```
Configure your keys in .env (Google Gemini AI API key, Ethereum RPC URL, Alchemy API key, ATP endpoint).

### 4.4 Running Locally
```bash
# Start all services concurrently (Frontend on :3000, API on :3001)
pnpm dev

# Or run individual services:
pnpm --filter api dev      # Fastify API & WebSocket service
pnpm --filter web dev      # Next.js 16 Web Dashboard
```

## 5. Cloud Deployment Guide (Render & Vercel)

Chain Sentinel is deployed as a resilient, high-performance distributed architecture:
- Fastify REST & WebSocket API: Hosted on Render (Web Service)
- Next.js 16 Web Dashboard: Hosted on Vercel (Production Edge Network)

### 5.1 Backend API & WebSocket Deployment on Render

Render hosts the autonomous multi-agent background workflows, real-time WebSocket feed, and mempool scanners.

1. Create a New Web Service:
   - Open the Render Dashboard (https://dashboard.render.com/).
   - Click "New +" and select "Web Service".
   - Connect the GitHub repository: `https://github.com/vismaygawai/chain.sentinel`.

2. Configure Build & Runtime Settings:
   - Name: `chain-sentinel-api` (or preferred name)
   - Region: Select preferred region (e.g. Oregon, Frankfurt, Ohio)
   - Branch: `master`
   - Root Directory: Leave blank (uses root of repository)
   - Runtime: `Node`
   - Build Command: `pnpm install`
   - Start Command: `pnpm --filter api start`
   - Instance Type: Free or Starter

3. Configure Environment Variables:
   Under the "Environment" tab in Render, define the following variables:
   - `PORT`: `10000`
   - `HOST`: `0.0.0.0`
   - `NODE_VERSION`: `24.x`
   - `GEMINI_API_KEY`: Your Google Gemini API key
   - `ALCHEMY_API_KEY`: Your Alchemy API key (for live mempool transaction streaming)
   - `ETH_RPC_URL`: `https://eth-mainnet.g.alchemy.com/v2/${ALCHEMY_API_KEY}` (or Ethereum RPC endpoint)
   - `ATP_API_URL`: `https://api.atp.network` (optional)
   - `ATP_AGENT_ID`: `cSNT-001` (optional)

4. Verify Deployment:
   - Click "Deploy Web Service".
   - Once deployed, your backend is live at `https://chain-sentinel.onrender.com`.
   - HTTP Health Check: `GET https://chain-sentinel.onrender.com/` returns status.
   - WebSocket Feed: Connect to `wss://chain-sentinel.onrender.com/ws/feed`.

---

### 5.2 Frontend Dashboard Deployment on Vercel

Vercel hosts the responsive Neo-Brutalist dashboard with Turbopack, automated SSR caching, and edge routing.

1. Import Project into Vercel:
   - Navigate to the Vercel Dashboard (https://vercel.com/dashboard).
   - Click "Add New..." -> "Project".
   - Select and import `https://github.com/vismaygawai/chain.sentinel`.

2. Configure Project Settings:
   - Project Name: `chain-sentinel-web`
   - Framework Preset: `Next.js`
   - Root Directory: Click "Edit" and choose `apps/web`
   - Production Branch: `master`
   - Node.js Version: In Project Settings -> General, select `24.x`.

3. Set Environment Variables:
   Add the following environment variables in the Vercel project configuration:
   - `NEXT_PUBLIC_API_URL`: `https://chain-sentinel.onrender.com` (Render API URL)
   - `NEXT_PUBLIC_WS_URL`: `wss://chain-sentinel.onrender.com/ws/feed` (Render WebSocket stream URL)

4. Deploy & Verify:
   - Click "Deploy".
   - Vercel installs workspace dependencies via pnpm and compiles the Next.js application.
   - Your dashboard is live at `https://chain-sentinel-web.vercel.app/`.

5. Continuous Integration & Automatic Deploys:
   - Any git push to the `master` branch triggers automated GitHub Actions CI & Lint workflows, Render backend re-deployments, and Vercel production deployments.

## 6. Design System & UI Specification

The frontend adheres strictly to a Neo-Brutalist aesthetic:
- Rigid Grid: Visual structural borders (border-2 border-black), 40px grid matrix.
- Zero-Blur Hard Shadows: High-impact contrast (box-shadow: 4px 4px 0px #000, 8px 8px 0px #000).
- Typography: Oversized Cabinet Grotesk headlines (72px+), Satoshi body text, and Instrument Serif italic editorial accents.
- Color Palette: Stark white (#ffffff), near-black (#0a0a0a), and electric blue (#0096ff).
- Interactive Hover-Reveal: Cards reveal hidden technical breakdowns, risk vectors, simulation diffs, and agent decision trees on hover.
- Asymmetric Shapes: Bento-style grid with asymmetric column spans and punchy hover scaling.

export class ScanController {
  public static async runRiskScan(
    request: FastifyRequest<{ Body: RiskScanRequestBody }>,
    reply: FastifyReply
  ) {
    const { address, policy } = request.body || {};
    if (!address || !isAddress(address)) {
      return reply.status(400).send({ error: 'A valid EVM Ethereum address is required' });
    }

    try {
      const result = await treasuryService.scanTreasury(address, policy);
      return reply.send(result);
    } catch (err: any) {
      request.log.error(err);
      return reply.status(500).send({
        error: 'Treasury risk scan failed',
        details: String(err?.message || err),
      });
    }
  }

  public static async registerWhale(
    request: FastifyRequest<{ Body: WhaleRegisterRequestBody }>,
    reply: FastifyReply
  ) {
    const { address } = request.body || {};
    if (!address || !isAddress(address)) {
      return reply.status(400).send({ error: 'A valid EVM address is required' });
    }
    const result = await treasuryService.registerWhaleWatch(address);
    return reply.send(result);
  }

  public static async registerPosition(
    request: FastifyRequest<{ Body: PositionRegisterRequestBody }>,
    reply: FastifyReply
  ) {
    const { address } = request.body || {};
    if (!address || !isAddress(address)) {
      return reply.status(400).send({ error: 'A valid EVM address is required' });
    }
    const result = await treasuryService.registerPosition(address);
    return reply.send(result);
  }

  public static async getAlerts(
    request: FastifyRequest<{ Querystring: AlertsQuery }>,
    reply: FastifyReply
  ) {
    const { address } = request.query;
    if (address && !isAddress(address)) {
      return reply.status(400).send({ error: 'Invalid address parameter' });
    }
    const result = treasuryService.getWhaleAlerts(address);
    return reply.send(result);
  }

  public static async getHealth(
    request: FastifyRequest<{ Querystring: HealthQuery }>,
    reply: FastifyReply
  ) {
    const { address } = request.query;
    if (!address || !isAddress(address)) {
      return reply.status(400).send({ error: 'A valid EVM address is required' });
    }
    const result = treasuryService.getHealthSnapshots(address);
    if (!result) {
      return reply.status(404).send({ error: 'No position snapshots found for address.' });
    }

export function errorHandler(
  error: FastifyError,
  request: FastifyRequest,
  reply: FastifyReply
) {
  const statusCode = error.statusCode || 500;
  if (statusCode >= 500) {
    request.log.error(error);
  } else {
    request.log.warn({ msg: error.message, statusCode });
  }

  const response: ApiErrorResponse = {
    error: error.message || 'Internal Server Error',
    statusCode,
    timestamp: new Date().toISOString(),
    details: ENV.NODE_ENV === 'development' ? error.stack : undefined,
  };

  reply.status(statusCode).send(response);
}

  await server.register(healthRoutes);

import type { FastifyInstance } from 'fastify';
import type { CompoundAlert } from 'agents-core';
import { alertCorrelator } from 'agents-core';
import type { WebSocket } from 'ws';

type AlertType = 'WHALE' | 'LIQUIDATION' | 'COMPOUND';

interface BroadcastMessage {
    type: AlertType;
    alert: CompoundAlert;
    data?: CompoundAlert;
    timestamp: string;
}

const MAX_REPLAY = 10;
const replayBuffer: BroadcastMessage[] = [];
const connectedClients = new Set<WebSocket>();
let isHookInitialized = false;

function classifyAlertType(alert: CompoundAlert): AlertType {
    if (alert.isCorrelated) return 'COMPOUND';
    if (alert.lsAlert && !alert.wwAlert) return 'LIQUIDATION';
    return 'WHALE';
}

function buildMessage(alert: CompoundAlert): BroadcastMessage {
    const type = classifyAlertType(alert);
    return {
        type,
        alert,
        data: alert,
        timestamp: new Date().toISOString(),
    };
}

function addToReplayBuffer(msg: BroadcastMessage): void {
    replayBuffer.push(msg);
    if (replayBuffer.length > MAX_REPLAY) {
        replayBuffer.shift();
    }
}

function broadcast(msg: BroadcastMessage): void {
    const payload = JSON.stringify(msg);
    for (const client of connectedClients) {
        if (client.readyState === 1) {
            client.send(payload);
        }
    }
}

function replayTo(client: WebSocket): void {
    for (const msg of replayBuffer) {
        client.send(JSON.stringify(msg));
    }
}

export function initCorrelatorHook(): void {
    if (isHookInitialized) return;
    isHookInitialized = true;
    alertCorrelator.onCompoundAlert((alert: any) => {
        const msg = buildMessage(alert);
        addToReplayBuffer(msg);
        broadcast(msg);
    });
}

export async function registerLiveFeed(fastify: FastifyInstance): Promise<void> {
    initCorrelatorHook();

    const handleConnection = (socket: any, _request: any) => {
        connectedClients.add(socket);

        socket.isAlive = true;
        socket.on('pong', () => { socket.isAlive = true; });

        socket.on('close', () => connectedClients.delete(socket));
        socket.on('error', () => connectedClients.delete(socket));
    };

    // Periodic heartbeat to evict dead sockets
    const pingInterval = setInterval(() => {
        for (const client of connectedClients) {
            const s = client as any;
            if (s.isAlive === false) {
                connectedClients.delete(client);
                try { client.terminate(); } catch {}
                continue;
            }
            s.isAlive = false;
            try { client.ping(); } catch { connectedClients.delete(client); }
        }
    }, 30000);
    pingInterval.unref?.();

# Chain Sentinel Web Console

The **Chain Sentinel Web Console** is a high-performance Next.js 15 operations dashboard built for real-time DeFi treasury surveillance, multi-agent exposure arbitration, and autonomous liquidation defense.

## Core Capabilities

- **Command Matrix & Surveillance HUD**: Real-time telemetry, continuous WebSocket alert stream, and active Agent Tokenization Platform (`cSNT`) registration badges.
- **On-Chain Risk & Exposure Scoring**: Interactive breakdown of treasury solvency, concentration, and Aave V3 lending health factor.
- **Dynamic Asset Allocation**: Interactive neo-brutalist asset distribution charts with compact token balance metrics.
- **Live Event Stream**: Real-time mempool whale activity and lending liquidation risk signals correlated in sliding time windows.
- **Autonomous Governance Simulation**: Visual execution of ADK-TS multi-agent defensive plans with policy constraints (Conservative, Balanced, Aggressive).

## Tech Stack

- **Framework**: Next.js 15 (App Router, Turbopack)
- **Styling**: Tailwind CSS with Neo-Brutalist design language (hard borders, high contrast, zero-blur hard shadows)
- **Web3 / Cryptography**: Ethers.js v6
- **Real-Time Streaming**: Fastify WebSocket feed with automated heartbeat & replay buffers
- **AI Agent Integration**: `@iqai/adk` multi-agent pipeline

## Local Development

From the repository root:

```bash
# Start frontend together with the API and agent workers
pnpm dev

# Or run frontend only
pnpm --filter web dev
```

The console will be accessible at [http://localhost:3000](http://localhost:3000).

    setAddressInput("");

    setWatchedPositions([]);

      const monitored = await getMonitoredWorkflows();
      
      // Deduplicate wallets by address to prevent React duplicate key errors
      const uniqueWalletsMap = new Map<string, WalletInfo>();
      for (const w of monitored) {
        if (w.address) {
          uniqueWalletsMap.set(w.address.toLowerCase(), w);

        const hasCollateralOrDebt =
          latestSnap &&
          (parseFloat(latestSnap.collateral || '0') > 0 || parseFloat(latestSnap.debt || '0') > 0);

        if (m.ls?.active && hasCollateralOrDebt && m.address) {
          uniquePositionsMap.set(m.address.toLowerCase(), {
            address: m.address,
            protocol: "aave-v3",
            snapshots: m.ls.lastSnapshot || [],
          });
        }
      }

import { useState, useEffect, useRef } from "react";
import type { ProtectionPlan, GovernanceDecision } from "@/types/index";

interface ActionListProps {

  decision?: GovernanceDecision | null;
}

export default function ActionList({ plan, decision }: ActionListProps) {
  const [executing, setExecuting] = useState(false);
  const [executed, setExecuted] = useState(false);
  const timer1 = useRef<NodeJS.Timeout | null>(null);
  const timer2 = useRef<NodeJS.Timeout | null>(null);

  const isLoaded = Boolean(decision || plan);
  const actions = decision?.enforcedActions || plan?.actions || [];
  const canSimulate = isLoaded && actions.length > 0 && decision?.approved !== false;

  const [prevTrigger, setPrevTrigger] = useState<unknown>(null);
  const currentTrigger = decision ?? plan;
  if (prevTrigger !== currentTrigger) {
    setPrevTrigger(currentTrigger);
    setExecuted(false);
    setExecuting(false);
  }

  useEffect(() => {
    return () => {
      if (timer1.current) clearTimeout(timer1.current);
      if (timer2.current) clearTimeout(timer2.current);
    };
  }, []);

  const handleSimulateExecution = () => {
    if (!canSimulate) return;
    setExecuting(true);
    timer1.current = setTimeout(() => {
      setExecuting(false);
      setExecuted(true);
      timer2.current = setTimeout(() => setExecuted(false), 5000);
    }, 1200);
  };

  return (
    <div className="border-2 border-black p-6 bg-white shadow-hard flex flex-col justify-between h-full space-y-6">
      
      {/* Top Content */}
      <div className="space-y-6">

        <div className="flex items-center justify-between border-b-2 border-black pb-3">

            <h3 className="font-display text-lg font-black uppercase tracking-tight">

            <p className="font-serif italic text-xs text-gray-600">
              Autonomous multi-agent consensus decisions
            </p>
          </div>
          <div className="flex items-center gap-2">

              <span className="font-mono text-xs bg-gray-100 text-gray-700 border border-gray-400 px-2.5 py-1 font-bold">
                STATUS: STANDBY
              </span>
            ) : decision?.approved !== false ? (
              <span className="font-mono text-xs bg-green-100 text-green-900 border border-green-700 px-2.5 py-1 font-bold">
                CONSENSUS: APPROVED
              </span>
            ) : (
              <span className="font-mono text-xs bg-red-100 text-red-900 border border-red-700 px-2.5 py-1 font-bold">
                CONSENSUS: BLOCKED
              </span>
            )}
          </div>
        </div>

        {/* Decision Rationale */}
        <div className="bg-[#f4f4f4] border border-black p-3.5 font-mono text-xs text-black">
          <span className="text-gray-500 font-bold block mb-1">
            ARBITRATION RATIONALE:
          </span>
          <p className="leading-relaxed">
            {decision?.reason || "Awaiting target scan to evaluate governance safety envelope."}
          </p>
        </div>

        {/* Actions List */}
        <div className="space-y-3">
          <span className="font-mono text-xs font-bold text-gray-500 block uppercase tracking-wider">

            ✓ Defensive Rebalance Successfully Simulated on Aave V3
          </div>
        ) : (
          <button
            onClick={handleSimulateExecution}
            disabled={!canSimulate || executing}
            className="w-full bg-black text-white hover:bg-electric border-2 border-black font-display text-xs font-black uppercase tracking-wider py-3.5 shadow-hard hover:shadow-hard-md active:translate-x-[2px] active:translate-y-[2px] active:shadow-none transition-all disabled:opacity-40 disabled:cursor-not-allowed"

function formatUSD(value: string | number): string {
  const num = typeof value === 'number' ? value : parseFloat(value);
  if (!isFinite(num) || isNaN(num)) return '$0.00';
  if (num >= 1_000_000_000) return `$${(num / 1_000_000_000).toFixed(2)}B`;
  if (num >= 1_000_000) return `$${(num / 1_000_000).toFixed(2)}M`;
  if (num >= 1_000) return `$${(num / 1_000).toFixed(1)}K`;
  return `$${num.toFixed(2)}`;
}

function formatTimestamp(timestamp: number): string {
  const diffMs = Date.now() - timestamp;
  const diffMin = Math.floor(diffMs / 60_000);

  if (diffMin < 1) return 'JUST NOW';
  if (diffMin < 60) return `${diffMin}M AGO`;
  if (diffMin < 1440) return `${Math.floor(diffMin / 60)}H AGO`;
  return new Date(timestamp).toLocaleDateString();
}

function getUrgencyConfig(urgency: string): { label: string; className: string } {
  switch (urgency) {
    case 'CRITICAL':

      return { label: 'HIGH', className: 'bg-orange-500 text-white' };
    case 'MEDIUM':
      return { label: 'MEDIUM', className: 'bg-yellow-400 text-black' };
    default:
      return { label: 'LOW', className: 'bg-electric text-white' };
  }
}

'use client'

import { useEffect, useState, useRef } from 'react'
import type { CompoundAlert } from '@/types'

const WS_URL = process.env.NEXT_PUBLIC_WS_URL || 'ws://localhost:3001/ws/feed'

export function useLiveFeed() {
    const [alerts, setAlerts] = useState<CompoundAlert[]>([])
    const [isConnected, setIsConnected] = useState(false)
    const ws = useRef<WebSocket | null>(null)
    const reconnectTimeout = useRef<NodeJS.Timeout | null>(null)

    useEffect(() => {
        function connect() {
            if (reconnectTimeout.current) {
                clearTimeout(reconnectTimeout.current)
                reconnectTimeout.current = null
            }

            ws.current = new WebSocket(WS_URL)

            ws.current.onopen = () => {
                console.log('[useLiveFeed] Connected to WebSocket')
                setIsConnected(true)
            }

            ws.current.onmessage = (event) => {
                try {
                    const data = JSON.parse(event.data)
                    // Broadcast format: { type: "WHALE"|"LIQUIDATION"|"COMPOUND", alert: {...}, timestamp: ISO }
                    if (data.alert) {
                        setAlerts((prev) => {
                            // Check for duplicates (by txHash or txHash + address)
                            const isDuplicate = prev.some(a => 
                                (a.wwAlert?.txHash && a.wwAlert?.txHash === data.alert.wwAlert?.txHash) ||
                                (a.walletAddress === data.alert.walletAddress && 
                                 JSON.stringify(a.lsAlert) === JSON.stringify(data.alert.lsAlert))
                            )
                            if (isDuplicate) return prev
                            return [data.alert, ...prev].slice(0, 50)
                        })
                    }
                } catch (err) {
                    console.error('[useLiveFeed] Message error:', err)
                }
            }

            ws.current.onclose = () => {
                console.log('[useLiveFeed] Disconnected')
                setIsConnected(false)
                // Attempt reconnect after 5s
                reconnectTimeout.current = setTimeout(connect, 5000)
            }

            ws.current.onerror = () => {
                // Only log error if we haven't successfully connected yet 
                // or if it's a persistent failure.
                if (ws.current?.readyState !== WebSocket.OPEN) {
                    console.warn('[useLiveFeed] WebSocket connection failed. Retrying...');
                }
                ws.current?.close()
            }
        }

        connect()

        return () => {
            if (reconnectTimeout.current) {
                clearTimeout(reconnectTimeout.current)
                reconnectTimeout.current = null
            }
            if (ws.current) {
                ws.current.onclose = null
                ws.current.close()
            }
        }
    }, [])

    return { alerts, isConnected }
}

import { useState, useCallback } from "react";
import type { TreasuryScanResult } from "@/types/index";
import { runRiskScan, registerWhaleWatcher, registerLiquidShield } from "@/lib/api";

export type ScanStep =
  | "IDLE"
  | "FETCHING_BALANCES"
  | "ANALYZING_RISK"
  | "GENERATING_PLAN"
  | "ENFORCING_GOVERNANCE"
  | "COMPLETE"
  | "ERROR";

export function useRiskScan() {
  const [step, setStep] = useState<ScanStep>("IDLE");
  const [loading, setLoading] = useState(false);
  const [result, setResult] = useState<TreasuryScanResult | null>(null);
  const [error, setError] = useState<string | null>(null);

  const scan = useCallback(async (address: string, policy?: string): Promise<TreasuryScanResult | null> => {
    if (!address.trim()) {
      setError("Please enter a valid Ethereum treasury or wallet address");
      return null;
    }

    setLoading(true);
    setError(null);
    setResult(null);
    setStep("FETCHING_BALANCES");

    try {
      // Start the actual network scan immediately
      const scanPromise = runRiskScan(address, policy);

      // Fast UI progression while awaiting network response
      const t1 = setTimeout(() => setStep("ANALYZING_RISK"), 150);
      const t2 = setTimeout(() => setStep("GENERATING_PLAN"), 350);
      const t3 = setTimeout(() => setStep("ENFORCING_GOVERNANCE"), 550);

      const scanResult = await scanPromise;

      clearTimeout(t1);
      clearTimeout(t2);
      clearTimeout(t3);

      // Only register LiquidShield if the wallet actually has an active lending position
      const hasLending =
        Boolean(scanResult?.risk?.healthFactor && scanResult.risk.healthFactor < 100) ||
        Boolean(scanResult?.snapshot?.positions?.some((p) => p.token === 'Aave V3 Collateral'));

      const monitoringTasks: Promise<unknown>[] = [registerWhaleWatcher(address)];
      if (hasLending) {
        monitoringTasks.push(registerLiquidShield(address));
      }
      await Promise.allSettled(monitoringTasks);

      setResult(scanResult);
      setStep("COMPLETE");
      return scanResult;
    } catch (err: unknown) {
      const msg = err instanceof Error ? err.message : String(err || "Failed to scan treasury. Verify connection.");
      setError(msg);
      setStep("ERROR");
      return null;
    } finally {
      setLoading(false);
    }
  }, []);

  const reset = useCallback(() => {
    setResult(null);
    setError(null);
    setStep("IDLE");
    setLoading(false);
  }, []);

  return {
    scan,
    reset,
    result,
    loading,
    error,
    step,
  };
}

export function formatCompactUSD(value: number | string): string {
  const num = typeof value === 'string' ? parseFloat(value) : value;
  if (!isFinite(num) || isNaN(num)) return "$0.00";
  const abs = Math.abs(num);
  if (abs >= 1e9) return `$${(num / 1e9).toFixed(2)}B`;
  if (abs >= 1e6) return `$${(num / 1e6).toFixed(2)}M`;
  if (abs >= 1e3) return `$${(num / 1e3).toFixed(2)}K`;
  return `$${num.toFixed(2)}`;
}

export function formatCompactNumber(value: number | string): string {
  const num = typeof value === 'string' ? parseFloat(value) : value;
  if (!isFinite(num) || isNaN(num)) return "0";
  const abs = Math.abs(num);
  if (abs >= 1e9) return `${(num / 1e9).toFixed(2)}B`;
  if (abs >= 1e6) return `${(num / 1e6).toFixed(2)}M`;
  if (abs >= 1e3) return `${(num / 1e3).toFixed(2)}K`;
  return num < 0.0001 && num > 0
    ? "<0.0001"
    : num.toLocaleString(undefined, { maximumFractionDigits: 4 });
}

  return date.toLocaleTimeString("en-US", {
    hour: "2-digit",
    minute: "2-digit",
    second: "2-digit",
  });

# Chain Sentinel — System Architecture Specification

## 1. Executive Summary

**Chain Sentinel** is a real-time, on-chain intelligence and autonomous defensive layer for decentralized finance (DeFi) treasuries and institutional wallets. 

While conventional DeFi security tools act **reactively** (generating alert notifications hours or days after an exploit or liquidation has occurred), Chain Sentinel is engineered **pre-emptively**: it continuously monitors lending health factors, intercepts mempool whale transactions, correlates compound threats across protocols, and autonomously arbitrates rebalancing actions before insolvency manifests.

Chain Sentinel was architected by **WWHS?** for **ELECTROTHON 8.0** ([Devfolio Submission](https://devfolio.co/projects/chain-sentinel-f7cf)).

---

## 2. Multi-Agent System Architecture (ADK-TS)

Chain Sentinel is constructed on top of **ADK-TS (`@iqai/adk`)**, the TypeScript Agent Development Kit. Agents operate as specialized autonomous entities coordinated through explicit state workflows and deterministic failsafes.

## 3. Specialized Agent Roles

### A. Watcher Agent (`watcherAgent.ts`)
- **Responsibility**: Inspects specified EVM treasury addresses across Ethereum and Layer 2 rollups.
- **Tools**: `ethers.JsonRpcProvider`, ERC-20 contract balance readers, multi-token price oracles.
- **Output**: Standardized `TreasurySnapshot` containing total USD asset valuation and individual token positions.

### B. WhaleWatch Scanner Agent (`scannerAgent.ts`)
- **Responsibility**: Subscribes to real-time pending transactions in the mempool exceeding $500,000 USD.
- **Tools**: Alchemy WebSocket filter, known address classification directory.
- **Output**: `WhaleScanResult` detailing source, destination, token, amount, and intent classification (Accumulation, Distribution, CEX Deposit).

### C. LiquidShield Monitor Agent (`monitorAgent.ts`)
- **Responsibility**: Continuously dequeues at-risk lending accounts using a prioritized risk-tier queue.
- **Tools**: Aave V3 `getUserAccountData` on-chain reader, historical health factor logger.
- **Output**: `PositionSnapshot` recording real-time Health Factor, total collateral USD, total borrow debt USD, and liquidation threshold.

### D. Threat Correlator Engine (`alertCorrelator.ts`)
- **Responsibility**: Discovers hidden compound systemic risks. If a monitored treasury exhibits low lending health factors while a connected whale dumps collateral into the mempool, the Correlator synthesizes a `CompoundAlert` with escalated urgency (`CRITICAL`).

### E. Risk Scoring Agent (`riskAgent.ts`)
- **Responsibility**: Computes composite threat score (0 to 100) and assigns risk tiers (`SAFE`, `WARNING`, `DANGER`, `CRITICAL`).
- **Safety Guarantee**: Employs deterministic mathematical scoring first; uses AI LLM analysis strictly for context enrichment.

### F. Protection Planner Agent (`plannerAgent.ts`)
- **Responsibility**: Synthesizes mitigation steps chosen from three constrained primitives:
  - `ALERT`: Notify operators and multisig signers.
  - `REDUCE`: Partially pay down risky lending debt.
  - `DIVERSIFY`: Reallocate concentrated volatile tokens into yield-bearing stablecoins.

### G. Governance Enforcement Agent (`governanceAgent.ts`)
- **Responsibility**: Acts as the ultimate safety arbiter.
- **Hard Safety Rule**: Hardcoded constraints that cannot be bypassed by LLM output. If risk is high and treasury exposure exceeds $1,000,000, emergency actions are automatically enforced regardless of model suggestions.

---

## 4. Agent Tokenization Platform (ATP) Integration

Chain Sentinel is registered with the **Agent Tokenization Platform (ATP)** under the symbol **`cSNT`**.

1. **Agent Identity Verification**: Cryptographically binds the multi-agent system code hash and ADK-TS configuration to an on-chain identity.
2. **Defensive Quota Tokens**: Users and DAOs hold tokenized protection quotas that incentivize continuous surveillance and cover autonomous rebalancing transaction fees.
3. **Transparent Execution**: Every risk assessment and governance decision is recorded with verifiable timestamps and deterministic state proofs.

---

## 5. Resilient Networking & Infrastructure

- **Fastify & WebSockets (`apps/api`)**: Asynchronous, non-blocking REST API and low-latency WebSocket broadcaster with replay buffers.
- **Failover JSON-RPC Pool (`rpcTools.ts`)**: Rotates across primary and secondary RPC providers with exponential backoff to ensure 99.99% on-chain liveness.
- **Semantic Vector Store (`vectorStore.ts`)**: In-memory cosine-similarity index comparing detected anomalies against historical DeFi exploit signatures.

### A. Sub-Second Compound Threat Detection

### B. Deterministic Safety Circuit Breaker
Unlike naive AI agent implementations that give full execution authority to an LLM, Chain Sentinel utilizes a **Deterministic Governance Circuit**:
- If total treasury exposure exceeds $1,000,000 USD and Risk Level is `HIGH`, emergency debt reduction actions are locked in mathematically.

### C. True Monorepo Architecture

import { createAgent } from '../lib/agentFactory.ts'
import type { PositionSnapshot } from '../types.ts'
import * as aaveTools from '../tools/aaveTools.ts'

export interface ActionRecommendation {
    suggestedAction: 'REPAY' | 'DEPOSIT'
    token: string
    amount: string
    slippagePct: number
}

export async function recommendAction(
    snapshot: PositionSnapshot,
): Promise<ActionRecommendation> {
    const repay = await aaveTools.calculateRepayAmount(snapshot)
    const debt = parseFloat(snapshot.debt)
    const repayAmount = parseFloat(repay.amount)
    const suggestedAction: 'REPAY' | 'DEPOSIT' =
        (debt > 0 && repayAmount > (debt * 0.01)) ? 'REPAY' : 'DEPOSIT'

    return {
        suggestedAction,
        token: repay.token,
        amount: repay.amount,
        slippagePct: repay.slippagePct,
    }
}

export interface WhaleAlert {
    txHash: string
    address: string
    amount: string
    token: string
    timestamp: number
    intent: IntentClassification
    label: string | null
}

export async function formatAlert(
    scan: WhaleScanResult,
    intent: IntentClassification,
    label: string | null,
): Promise<WhaleAlert | null> {
    const redis = getRedisClient()
    const key = `dedup:tx:${scan.txHash}`
    const isNew = await redis.set(key, '1', 'EX', 3600, 'NX')
    if (!isNew) return null
    return {
        txHash: scan.txHash,
        address: scan.address,
        amount: scan.amount,
        token: scan.token,
        timestamp: scan.timestamp,
        intent,
        label,
    }
}

export async function routeToCorrelator(alert: WhaleAlert): Promise<void> {
    const { ingestWhaleAlert } = await import('../correlation/alertCorrelator.ts')
    ingestWhaleAlert({
        address: alert.address,
        amount: alert.amount,
        token: alert.token,
        timestamp: alert.timestamp,
        txHash: alert.txHash,
        intent: alert.intent,
        label: alert.label || undefined,
    })
    console.log(`[alertAgent] Routed alert to correlator: ${alert.txHash} (${alert.intent})`)
}

Return STRICT JSON ONLY:

export async function enforceGovernance(
  input: {
    risk: RiskResult;
    plan: ProtectionPlan;
    totalUsdValue: number;
    policy?: string;
  }
): Promise<GovernanceDecision> {
  const { risk, plan, totalUsdValue, policy: policyName } = input;
  const policy = getPolicy(policyName || 'CONSERVATIVE');

  // HARD SAFETY RULE: Require manual multisig or block if high risk on significant treasury
  if (risk.level === "HIGH" && (totalUsdValue > 1_000_000 || policy.requireMultiSigApproval)) {
    console.log(`[governanceAgent] Hard safety rule triggered: HIGH risk on $${(totalUsdValue / 1e6).toFixed(2)}M treasury under ${policy.name} policy`);
    return {
      approved: false,
      reason: `CRITICAL: High risk under ${policy.name} policy (${policy.requireMultiSigApproval ? 'Multi-Sig Required' : 'Exposure Limit Exceeded'}). Manual governance intervention required.`,
      enforcedActions: [
        {
          type: "ALERT",
          message: `Governance blocked automated execution under ${policy.name} policy due to high risk threshold.`
        }
      ]
    };
  }

  try {
    // Ensure agent is initialized
    if (!governanceRunner) {
      await initGovernanceAgent();
    }

    const prompt = `TASK: Make final safety approval decision for treasury.

POLICY ENFORCEMENT:
- Policy Name: ${policy.name}
- Target Min Health Factor: ${policy.minHealthFactor}
- Max Single Asset Concentration: ${policy.maxSingleAssetConcentrationPct}%
- MultiSig Required for High Value: ${policy.requireMultiSigApproval}

RISK SUMMARY:
- Level: ${risk.level}
- Score: ${risk.score}/100  
- Treasury: $${(totalUsdValue / 1e6).toFixed(2)}M

PROPOSED PROTECTION ACTIONS:
${plan.actions.map((a, i) => `${i + 1}. ${a.type}: "${a.message}"`).join("\n")}

ENFORCEMENT RULES:
- HIGH risk + treasury >$1M = Block (safety override)
- MEDIUM risk = Approve protective actions (REDUCE, DIVERSIFY, ALERT)
- LOW risk = Approve actions within policy guidelines
- Never approve risky actions on large treasuries

OUTPUT ONLY THIS JSON:
{"approved":true|false,"reason":"brief explanation of decision","enforcedActions":[{"type":"ALERT"|"REDUCE"|"DIVERSIFY","message":"action to enforce"}]}`;

    let response = '';
    if (process.env.GEMINI_API_KEY && (governanceAgent || governanceRunner)) {
      try {
        if (typeof governanceAgent?.run === 'function') {
          const res = await governanceAgent.run(prompt);
          response = typeof res === 'string' ? res : (res?.text || JSON.stringify(res));
        } else if (typeof governanceRunner?.run === 'function') {
          const res = await governanceRunner.run(prompt);
          response = typeof res === 'string' ? res : (res?.text || JSON.stringify(res));
        }
      } catch (adkErr) {
        console.warn("[governanceAgent] ADK governance execution failed, attempting fallback:", adkErr);
      }
    }

    if (!response) {
      response = await callQwenLLM(prompt);
    }
    console.log("[governanceAgent] LLM response received");

    const parsed = extractJSON<GovernanceDecision>(response);

    // Validate and normalize
    if (parsed && typeof parsed.approved === "boolean") {
      console.log(`[governanceAgent] Governance decision from LLM: ${parsed.approved ? "APPROVED" : "BLOCKED"}`);
      return {
        approved: parsed.approved,
        reason: parsed.reason || "No reason provided",
        enforcedActions: (parsed.enforcedActions || []).map((a: any) => ({
          type: ["ALERT", "REDUCE", "DIVERSIFY"].includes(a.type) ? a.type : "ALERT",
          message: String(a.message)
        }))
      };
    }
  } catch (err) {
    console.warn("[governanceAgent] LLM governance fallback activated:", err instanceof Error ? err.message : String(err));
  }

  // ADK-style deterministic fallback
  if (risk.level === "MEDIUM") {
    console.log(`[governanceAgent] Governance decision from deterministic rule (MEDIUM risk, ${policy.name} policy)`);
    return {
      approved: true,
      reason: `Moderate risk detected. Protective actions approved under ${policy.name} policy guidelines.`,
      enforcedActions: plan.actions.filter((a: any) => ["DIVERSIFY", "ALERT"].includes(a.type))
    };
  }

  if (risk.level === "LOW" || risk.tier === "SAFE") {
    console.log(`[governanceAgent] Governance decision from deterministic rule (LOW risk, ${policy.name} policy)`);
    return {
      approved: true,
      reason: `Low risk treasury. All protection actions approved under ${policy.name} policy.`,
      enforcedActions: plan.actions
    };
  }

  console.log("[governanceAgent] Governance decision from deterministic rule (default fallback)");
  return {
    approved: false,
    reason: `Unrecognized risk state under ${policy.name} policy. Governance blocked automation.`,
    enforcedActions: [
      {
        type: "ALERT",
        message: "Governance fallback activated."
      }
    ]
  };
}

import { createAgent } from '../lib/agentFactory.ts';
import * as walletTools from '../tools/walletTools.ts';
import { threatVectorStore } from '../memory/vectorStore.ts';

export type IntentClassification =
    | 'CEX_DEPOSIT'
    | 'ACCUMULATION'
    | 'DISTRIBUTION'
    | 'UNKNOWN';

export interface IntentResult {
    address: string;
    label: string | null;
    intent: IntentClassification;
    source: 'local' | 'llm';
}

const INTENT_PATTERNS = [
    { regex: /hot\s?wallet|cex|coinbase|binance|kraken|kucoin|bybit|okx|huobi|gate\.io|bitfinex/i, intent: 'CEX_DEPOSIT' },
    { regex: /treasury|dao|foundation|exploiter|hacker|multisig|vault/i, intent: 'ACCUMULATION' },
    { regex: /distributor|airdrop|deployer|router/i, intent: 'DISTRIBUTION' },
] as const;

function inferIntentFromLabel(label: string): IntentClassification {
    for (const { regex, intent } of INTENT_PATTERNS) {
        if (regex.test(label)) {
            return intent;
        }
    }
    return 'UNKNOWN';
}

export async function classifyIntent(address: string): Promise<IntentResult> {
    const label = walletTools.lookupLabel(address);
    if (label) {
        const intent = inferIntentFromLabel(label);
        return { address, label, intent: intent === 'UNKNOWN' ? 'ACCUMULATION' : intent, source: 'local' };
    }

    // Query threat vector store for matching historical patterns
    const similar = threatVectorStore.querySimilar(address, 1)[0];
    if (similar && similar.similarity > 0.2) {
        return {
            address,
            label: `${similar.incident.protocol} Pattern`,
            intent: 'DISTRIBUTION',
            source: 'llm',
        };
    }

    return { address, label: 'Mempool Whale', intent: 'DISTRIBUTION', source: 'local' };
}

    tools: [walletTools.lookupLabel],

const PIPELINE = 'ls'

export interface LSGovernanceDecision {
    allowed: boolean
    reason: string
    criticalOverride: boolean
}

export async function evaluateAlert(
    address: string,
    healthFactor: number,
    confidence: number,
): Promise<LSGovernanceDecision> {
    if (healthFactor < 1.1 && LS_POLICIES.CRITICAL_OVERRIDE) {
        return {
            allowed: true,
            reason: `CRITICAL_OVERRIDE: HF ${healthFactor.toFixed(4)} < 1.1 — all gates bypassed`,
            criticalOverride: true,
        }
    }

    if (confidence < LS_POLICIES.MIN_CONFIDENCE) {
        return {
            allowed: false,
            reason: `Confidence ${confidence} below minimum ${LS_POLICIES.MIN_CONFIDENCE}`,
            criticalOverride: false,
        }
    }

    const onCooldown = await alertCooldown.isCooledDown(PIPELINE, address)
    if (onCooldown) {
        return {
            allowed: false,
            reason: `Address ${address} is on cooldown (${LS_POLICIES.COOLDOWN_MS / 60_000} min)`,
            criticalOverride: false,
        }
    }

    await alertCooldown.setCooldown(PIPELINE, address, LS_POLICIES.COOLDOWN_MS)
    return {
        allowed: true,
        reason: 'Passed all policy gates',
        criticalOverride: false,
    }
}

        }
      ]
    };
  }

  return {
    actions: [
      {
        type: "ALERT",
        message: `Treasury is stable within ${policy.name} policy bounds. Monitor regularly.`
      }
    ]
  };

export const RiskSignalSchema = z.object({
  address: z.string(),
  score: z.number().min(0).max(100),
  level: z.enum(['LOW', 'MEDIUM', 'HIGH']),
  tier: z.enum(['SAFE', 'WARNING', 'DANGER', 'CRITICAL']),
  healthFactor: z.number().optional(),
  issues: z.array(z.string()),
  narrative: z.string(),

export interface RiskAssessment extends RiskResult {
  address: string;
  healthFactor?: number;
  tier: RiskTier;
  score: number;
  narrative: string;
  source: 'deterministic' | 'llm-enriched';
}

export function deterministicScore(address: string, healthFactor?: number): RiskAssessment {
  const hf = healthFactor && healthFactor > 0 ? healthFactor : 0;
  const hasDebt = hf > 0;
  const tier = hasDebt ? classifyTier(hf) : 'SAFE';
  let score: number;
  if (!hasDebt) score = 10;
  else if (hf < 1.0) score = 100;
  else if (hf < 1.1) score = 95;
  else if (hf < 1.3) score = 75;
  else if (hf < 2.0) score = 40;
  else score = 15;

  const level: 'LOW' | 'MEDIUM' | 'HIGH' =
    tier === 'CRITICAL' || tier === 'DANGER' ? 'HIGH' : tier === 'WARNING' ? 'MEDIUM' : 'LOW';

  const issues: string[] = [];
  if (hasDebt && hf < 1.3) {
    issues.push(`Low Aave V3 health factor: ${hf.toFixed(2)} (liquidation threshold at 1.00)`);
  }

  return {
    address,
    healthFactor: hasDebt ? hf : undefined,
    tier,
    score,
    narrative: hasDebt
      ? `Health factor ${hf.toFixed(2)} classified as ${tier} (${score}/100 risk score).`
      : `No active borrow debt. Treasury profile in safe baseline state (${score}/100 score).`,
    source: 'deterministic',
    level,
    issues,
  };
}

export async function llmEnrich(assessment: RiskAssessment): Promise<RiskAssessment> {
  if (assessment.healthFactor && assessment.healthFactor > 0 && assessment.healthFactor < 1.1) {
    const res = {
      ...assessment,
      narrative: `CRITICAL: Health factor at ${assessment.healthFactor.toFixed(4)} — immediate debt repayment required.`,
    };
    return RiskSignalSchema.parse(res);
  }
  const similar = threatVectorStore.querySimilar(assessment.narrative, 1)[0];
  const enrichedNarrative =
    similar && similar.similarity > 0.25
      ? `${assessment.narrative} Pattern matches ${similar.incident.protocol} (${similar.incident.type}): ${similar.incident.recommendedMitigation}.`
      : assessment.narrative;

  const res = { ...assessment, narrative: enrichedNarrative, source: 'llm-enriched' as const };
  return RiskSignalSchema.parse(res);
}

export async function assessRisk(
  addressOrSnapshot: string | TreasurySnapshot,
  healthFactorOrPolicy?: number | string
): Promise<RiskAssessment> {
  if (typeof addressOrSnapshot === 'object' && addressOrSnapshot.totalUsdValue !== undefined) {
    const snapshot = addressOrSnapshot;
    const policyName = typeof healthFactorOrPolicy === 'string' ? healthFactorOrPolicy : 'CONSERVATIVE';
    const policy = getPolicy(policyName);

    let hf: number | undefined = undefined;
    let hasDebt = false;
    try {
      const aaveData = await fetchAaveUserAccountData(snapshot.address);
      hasDebt = aaveData.totalDebtUSD > 0;
      if (hasDebt && aaveData.healthFactor > 0) {
        hf = aaveData.healthFactor;
      }
    } catch {
      // If Aave account data fails to fetch, wallet has no active lending debt
    }

    // Calculate max single-asset concentration
    let maxAssetPct = 0;
    let dominantToken = 'ETH';
    if (snapshot.totalUsdValue > 0) {
      for (const pos of snapshot.positions) {
        const pct = (pos.usdValue / snapshot.totalUsdValue) * 100;
        if (pct > maxAssetPct) {
          maxAssetPct = pct;
          dominantToken = pos.token;
        }
      }
    }

    const issues: string[] = [];
    let score = 15;

    if (hasDebt && hf !== undefined && hf < policy.minHealthFactor) {
      score += hf < 1.15 ? 65 : hf < 1.35 ? 45 : 25;
      issues.push(
        `Health factor ${hf.toFixed(2)} is below ${policy.name} policy minimum (${policy.minHealthFactor.toFixed(2)})`
      );
    }

    if (snapshot.totalUsdValue > 0 && maxAssetPct > policy.maxSingleAssetConcentrationPct) {
      const stableTokens = ['USDT', 'USDC', 'DAI'];
      const concentrationPenalty = stableTokens.includes(dominantToken) ? 10 : 25;
      score += concentrationPenalty;
      issues.push(
        `${dominantToken} concentration (${maxAssetPct.toFixed(1)}%) exceeds ${policy.name} limit (${policy.maxSingleAssetConcentrationPct}%)`
      );
    }

    score = Math.min(100, Math.max(5, score));
    const level: 'LOW' | 'MEDIUM' | 'HIGH' = score >= 70 ? 'HIGH' : score >= 40 ? 'MEDIUM' : 'LOW';
    const tier: RiskTier =
      score >= 85 ? 'CRITICAL' : score >= 70 ? 'DANGER' : score >= 40 ? 'WARNING' : 'SAFE';

    const base: RiskAssessment = {
      address: snapshot.address,
      healthFactor: hasDebt ? hf : undefined,
      tier,
      score,
      narrative:
        issues.length > 0
          ? `Detected ${issues.length} policy violation(s) under ${policy.name} profile.`
          : `Treasury reserves ($${snapshot.totalUsdValue.toLocaleString()}) comply with ${policy.name} risk bounds.`,
      source: 'deterministic',
      level,
      issues,
    };

    return llmEnrich(base);
  }

  const targetAddress =
    typeof addressOrSnapshot === 'string'
      ? addressOrSnapshot
      : (addressOrSnapshot as TreasurySnapshot).address || '';

  const base = deterministicScore(
    targetAddress,
    typeof healthFactorOrPolicy === 'number' ? healthFactorOrPolicy : undefined
  );
  return llmEnrich(base);
}

export async function watchTreasury(address: string): Promise<TreasurySnapshot> {
  const normalizedAddress = ethers.getAddress(address.toLowerCase());
  const prices = await getBatchPrices(['ETH', ...TOKENS.map((t) => t.symbol)]);

  try {
    return await withResilientProvider('ethereum', async (provider) => {
      const balanceWei = await provider.getBalance(normalizedAddress);
      const balanceEth = Number(ethers.formatEther(balanceWei));
      const ethUsd = balanceEth * (prices.ETH || 2850);

      let totalUsdValue = ethUsd;
      const positions = [{ token: 'ETH', balance: balanceEth, usdValue: ethUsd }];

      const tokenBalances = await Promise.allSettled(
        TOKENS.map(async (token) => {
          const contract = new ethers.Contract(token.address, ERC20_ABI, provider);
          const rawBalance: bigint = await contract.balanceOf(normalizedAddress);
          const formatted = Number(ethers.formatUnits(rawBalance, token.decimals));
          return { symbol: token.symbol, balance: formatted };
        })
      );

      for (const res of tokenBalances) {
        if (res.status === 'fulfilled' && res.value.balance > 0) {
          const price = prices[res.value.symbol] ?? 1.0;
          const usdValue = res.value.balance * price;
          totalUsdValue += usdValue;
          positions.push({
            token: res.value.symbol,
            balance: res.value.balance,
            usdValue,
          });
        }
      }

      try {
        const aaveData = await fetchAaveUserAccountData(normalizedAddress, provider);
        if (aaveData.totalCollateralUSD > 0) {
          totalUsdValue += aaveData.totalCollateralUSD;
          positions.push({
            token: 'Aave V3 Collateral',
            balance: 1,
            usdValue: aaveData.totalCollateralUSD,
          });
        }
      } catch {
        // Not active on Aave V3 or contract call failed; keep token balances
      }

      console.log(`[watcherAgent] Scanned ${normalizedAddress}: Total=$${totalUsdValue.toFixed(2)} (${positions.length} assets)`);
      return { address: normalizedAddress, totalUsdValue, positions };
    });
  } catch (err) {
    console.warn(`[watcherAgent] All RPC endpoints unreachable for ${normalizedAddress}:`, err);
    return {
      address: normalizedAddress,
      totalUsdValue: 0,
      positions: [{ token: 'ETH', balance: 0, usdValue: 0 }],
    };
  }
}

import type {
    WhaleScanResult,
    PositionSnapshot,
    CompoundAlert,
} from '../types.ts';

const CORRELATION_WINDOW_MS = 15 * 60_000; // 15-minute sliding window

interface WindowEntry<T> {
    data: T;
    receivedAt: number;
}

const whaleWindow = new Map<string, WindowEntry<WhaleScanResult>>();
const liquidationWindow = new Map<string, WindowEntry<PositionSnapshot>>();
const alertHistory: CompoundAlert[] = [];
const MAX_HISTORY = 50;

type CompoundAlertHandler = (alert: CompoundAlert) => void;
const handlers: CompoundAlertHandler[] = [];

export function onCompoundAlert(handler: CompoundAlertHandler): void {
    handlers.push(handler);
}

function emit(alert: CompoundAlert): void {
    alertHistory.unshift(alert);
    if (alertHistory.length > MAX_HISTORY) {
        alertHistory.pop();
    }
    for (const handler of handlers) {
        handler(alert);
    }
}

export function getRecentAlerts(address?: string): CompoundAlert[] {
    if (address) {
        const norm = address.toLowerCase();
        return alertHistory.filter(a => a.walletAddress?.toLowerCase() === norm);
    }
    return [...alertHistory];
}

function purgeStale(): void {
    const cutoff = Date.now() - CORRELATION_WINDOW_MS;
    for (const [addr, entry] of whaleWindow) {
        if (entry.receivedAt < cutoff) whaleWindow.delete(addr);
    }
    for (const [addr, entry] of liquidationWindow) {
        if (entry.receivedAt < cutoff) liquidationWindow.delete(addr);
    }
}

function determineUrgency(
    isCorrelated: boolean,
    snapshot?: PositionSnapshot,
): CompoundAlert['combinedUrgency'] {
    if (isCorrelated) return 'CRITICAL';
    if (snapshot) {
        const hf = parseFloat(snapshot.healthFactor);
        if (hf < 1.1) return 'CRITICAL';
        if (hf < 1.3) return 'HIGH';
        if (hf < 2.0) return 'MEDIUM';
    }
    return 'LOW';
}

export function ingestWhaleAlert(scan: WhaleScanResult): CompoundAlert {
    purgeStale();
    const addr = scan.address.toLowerCase();
    const now = Date.now();
    whaleWindow.set(addr, { data: scan, receivedAt: now });
    const lsEntry = liquidationWindow.get(addr);
    const isCorrelated = !!lsEntry && (now - lsEntry.receivedAt) <= CORRELATION_WINDOW_MS;
    const alert: CompoundAlert = {
        walletAddress: addr,
        wwAlert: scan,
        lsAlert: isCorrelated ? lsEntry.data : undefined,
        isCorrelated,
        combinedUrgency: determineUrgency(isCorrelated, lsEntry?.data),
    };
    emit(alert);
    return alert;
}

export function ingestLiquidationAlert(snapshot: PositionSnapshot): CompoundAlert {
    purgeStale();
    const addr = snapshot.walletAddress.toLowerCase();
    const now = Date.now();
    liquidationWindow.set(addr, { data: snapshot, receivedAt: now });
    const wwEntry = whaleWindow.get(addr);
    const isCorrelated = !!wwEntry && (now - wwEntry.receivedAt) <= CORRELATION_WINDOW_MS;
    const alert: CompoundAlert = {
        walletAddress: addr,
        wwAlert: isCorrelated ? wwEntry.data : undefined,
        lsAlert: snapshot,
        isCorrelated,
        combinedUrgency: determineUrgency(isCorrelated, snapshot),
    };
    emit(alert);
    return alert;
}

export function windowStats(): { whaleCount: number; liquidationCount: number; activeWhaleAlerts: number; activeLiquidationAlerts: number } {
    purgeStale();
    return {
        whaleCount: whaleWindow.size,
        liquidationCount: liquidationWindow.size,
        activeWhaleAlerts: whaleWindow.size,
        activeLiquidationAlerts: liquidationWindow.size,
    };
}

export function reset(): void {
    whaleWindow.clear();
    liquidationWindow.clear();
    alertHistory.length = 0;
    handlers.length = 0;
}

interface DBData {
  wallets: any[];
  positions: any[];
  users: any[];
}

function readDB(): DBData {
  if (!fs.existsSync(DB_PATH)) {
    return { wallets: [], positions: [], users: [] };
  }
  try {
    return JSON.parse(fs.readFileSync(DB_PATH, 'utf-8'));
  } catch {
    return { wallets: [], positions: [], users: [] };
  }
}

function writeDB(data: DBData) {
  try {
    fs.writeFileSync(DB_PATH, JSON.stringify(data, null, 2));
  } catch {
    // Ignore in-memory fallback
  }
}

export const prisma = {
  wallet: {
    findMany: async () => {
      const wallets = readDB().wallets || [];
      const seen = new Set<string>();
      return wallets.filter((w: any) => {
        const key = w.address?.toLowerCase();
        if (!key || seen.has(key)) return false;
        seen.add(key);
        return true;
      });
    },
    create: async ({ data }: any) => {
      const db = readDB();
      if (!db.wallets) db.wallets = [];
      const existingIdx = db.wallets.findIndex(
        (w: any) => w.address?.toLowerCase() === data.address?.toLowerCase()
      );
      if (existingIdx >= 0) {
        db.wallets[existingIdx] = { ...db.wallets[existingIdx], ...data };
      } else {
        db.wallets.push(data);
      }
      writeDB(db);
      return data;
    },
    deleteMany: async () => {
      const db = readDB();
      db.wallets = [];
      writeDB(db);
    },
  },
  user: {
    count: async () => (readDB().users || []).length,
  },
} as any;

  id: string;
  protocol: string;
  type: 'FLASH_LOAN' | 'ORACLE_MANIPULATION' | 'LIQUIDATION_CASCADE' | 'REENTRANCY' | 'BRIDGE_EXPLOIT' | 'UNUSUAL_WHALE';

  timestamp: number;
}

export interface SimilarityMatch {
  incident: SecurityIncident;
  similarity: number;

/**
 * Calculates cosine similarity between two numerical vectors
 */
export function cosineSimilarity(a: number[], b: number[]): number {
  if (a.length !== b.length || a.length === 0) return 0;
  let dotProduct = 0;
  let normA = 0;
  let normB = 0;
  for (let i = 0; i < a.length; i++) {
    dotProduct += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  if (normA === 0 || normB === 0) return 0;
  return dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
}

/**
 * Deterministic bag-of-words / character n-gram feature vectorizer
 * Allows similarity querying without requiring external vector database services
 */
export function pseudoEmbedText(text: string, dimensions: number = 32): number[] {
  const vector = new Array(dimensions).fill(0);
  const words = text.toLowerCase().replace(/[^a-z0-9 ]/g, '').split(/\s+/);
  
  for (let i = 0; i < words.length; i++) {
    const word = words[i];
    let hash = 0;
    for (let c = 0; c < word.length; c++) {
      hash = (hash << 5) - hash + word.charCodeAt(c);
      hash |= 0;
    }
    const idx = Math.abs(hash) % dimensions;
    vector[idx] += 1;
  }

  // Normalize vector to unit length
  const mag = Math.sqrt(vector.reduce((acc, v) => acc + v * v, 0));
  if (mag > 0) {
    for (let i = 0; i < dimensions; i++) {
      vector[i] /= mag;
    }
  }
  return vector;
}

/**
 * Risk-tiered priority queue for LiquidShield scan scheduling.
 * 
 * Tiers (based on Aave health factor):
 *   CRITICAL  HF < 1.10  → scan every 12s   (1 Ethereum block)
 *   DANGER    HF < 1.30  → scan every 30s
 *   WARNING   HF < 2.00  → scan every 2 min
 *   SAFE      HF ≥ 2.00  → scan every 10 min
 */

export type RiskTier = 'CRITICAL' | 'DANGER' | 'WARNING' | 'SAFE'

export const TIER_INTERVALS: Record<RiskTier, number> = {
    CRITICAL: 12_000,
    DANGER: 30_000,
    WARNING: 120_000,
    SAFE: 600_000,
} as const

export interface QueueEntry {
    address: string
    tier: RiskTier
    intervalMs: number
    nextScanAt: number
}

const queue: Map<string, QueueEntry> = new Map()

export function classifyTier(healthFactor: number): RiskTier {
    if (healthFactor < 1.1) return 'CRITICAL'
    if (healthFactor < 1.3) return 'DANGER'
    if (healthFactor < 2.0) return 'WARNING'
    return 'SAFE'
}

export function enqueue(address: string, healthFactor: number): void {
    const tier = classifyTier(healthFactor)
    const intervalMs = TIER_INTERVALS[tier]
    queue.set(address.toLowerCase(), {
        address: address.toLowerCase(),
        tier,
        intervalMs,
        nextScanAt: Date.now(),
    })
}

export function dequeueNext(): QueueEntry | undefined {
    const now = Date.now()
    let earliest: QueueEntry | undefined
    for (const entry of queue.values()) {
        if (entry.nextScanAt <= now) {
            if (!earliest || entry.nextScanAt < earliest.nextScanAt) {
                earliest = entry
            }
        }
    }
    if (earliest) {
        earliest.nextScanAt = now + earliest.intervalMs
        queue.set(earliest.address, earliest)
    }
    return earliest
}

export function updateTier(address: string, healthFactor: number): void {
    const key = address.toLowerCase()
    const existing = queue.get(key)
    const newTier = classifyTier(healthFactor)
    const newInterval = TIER_INTERVALS[newTier]
    if (existing) {
        if (newInterval < existing.intervalMs) {
            existing.nextScanAt = Math.min(existing.nextScanAt, Date.now() + newInterval)
        }
        existing.tier = newTier
        existing.intervalMs = newInterval
        queue.set(key, existing)
    } else {
        enqueue(address, healthFactor)
    }
}

export function remove(address: string): boolean {
    return queue.delete(address.toLowerCase())
}

export function size(): number {
    return queue.size
}

export function snapshot(): QueueEntry[] {
    return Array.from(queue.values()).sort((a, b) => a.nextScanAt - b.nextScanAt)
}

class LocalRedisMock extends EventEmitter {
    private storage: Map<string, any> = new Map();
    private timers: Map<string, NodeJS.Timeout> = new Map();

    async set(key: string, value: any, mode?: string, duration?: number, flag?: string) {
        if (flag === 'NX' && this.storage.has(key)) {
            return null;
        }
        if (flag === 'XX' && !this.storage.has(key)) {
            return null;
        }
        if (this.timers.has(key)) {
            clearTimeout(this.timers.get(key)!);
            this.timers.delete(key);
        }
        this.storage.set(key, value);
        if ((mode === 'EX' || mode === 'PX') && duration) {
            const ttl = mode === 'EX' ? duration * 1000 : duration;
            const timer = setTimeout(() => {
                this.storage.delete(key);
                this.timers.delete(key);
            }, ttl);
            timer.unref?.();
            this.timers.set(key, timer);
        }
        return 'OK';
    }

    async get(key: string) {
        return this.storage.get(key) || null;
    }

    async exists(key: string) {
        return this.storage.has(key) ? 1 : 0;
    }

    async del(...keys: string[]) {
        let count = 0;
        for (const k of keys) {
            if (this.timers.has(k)) {
                clearTimeout(this.timers.get(k)!);
                this.timers.delete(k);
            }
            if (this.storage.delete(k)) {
                count++;
            }
        }
        return count;
    }

    async lpush(key: string, ...values: string[]) {
        const list = this.storage.get(key) || [];
        list.unshift(...values);
        this.storage.set(key, list);
        return list.length;
    }

    async lrange(key: string, start: number, stop: number) {
        const list = this.storage.get(key) || [];
        if (stop === -1) return list.slice(start);
        return list.slice(start, stop + 1);
    }

    async keys(pattern: string) {
        const escaped = pattern.replace(/[.+?^${}()|[\]\\]/g, '\\$&').replace(/\*/g, '.*');
        const regex = new RegExp(`^${escaped}$`);
        return Array.from(this.storage.keys()).filter(k => regex.test(k));
    }

    pipeline() {
        const queue: Array<() => Promise<any> | any> = [];
        const pipe = {
            lpush: (key: string, val: string) => {
                queue.push(() => this.lpush(key, val));
                return pipe;
            },
            ltrim: (key: string, start: number, stop: number) => {
                queue.push(() => {
                    const list = this.storage.get(key) || [];
                    this.storage.set(key, list.slice(start, stop + 1));
                });
                return pipe;
            },
            set: (key: string, value: any, mode?: string, duration?: number, flag?: string) => {
                queue.push(() => this.set(key, value, mode, duration, flag));
                return pipe;
            },
            del: (...keys: string[]) => {
                queue.push(() => this.del(...keys));
                return pipe;
            },
            exec: async () => {
                const results = [];
                for (const op of queue) {
                    results.push(await op());
                }
                return results;
            },
        };
        return pipe as any;
    }

    async quit() {
        for (const timer of this.timers.values()) {
            clearTimeout(timer);
        }
        this.timers.clear();
        this.storage.clear();
        return 'OK';
    }
}

const AAVE_V3_POOL_ABI = [

// Ethereum Mainnet Aave V3 Pool Address
export const AAVE_V3_POOL_ADDRESS = '0x87870Bca3F3fD6335C3F4ce8392D69350B4fA4E2';

export interface UserAccountData {
  totalCollateralUSD: number;
  totalDebtUSD: number;
  availableBorrowsUSD: number;
  currentLiquidationThreshold: number;
  ltv: number;
  healthFactor: number;
  isAtRisk: boolean;
  distanceToLiquidationPct: number;

/**
 * Fetch live Aave V3 account data from on-chain contract with automatic fallback
 */
export async function fetchAaveUserAccountData(
  walletAddress: string,
  providerOrUrl: ethers.Provider | string = 'https://ethereum.publicnode.com'
): Promise<UserAccountData> {
  try {
    const provider =
      typeof providerOrUrl === 'string'
        ? new ethers.JsonRpcProvider(providerOrUrl)
        : providerOrUrl;

    const normalizedAddress = ethers.getAddress(walletAddress);
    const contract = new ethers.Contract(AAVE_V3_POOL_ADDRESS, AAVE_V3_POOL_ABI, provider);

    const [
      totalCollateralBase,
      totalDebtBase,
      availableBorrowsBase,
      currentLiquidationThreshold,
      ltv,
      healthFactor,
    ] = await contract.getUserAccountData(normalizedAddress);

    // Aave base currency units are in 8 decimals (USD value with 8 decimals)
    const collateralUSD = Number(totalCollateralBase) / 1e8;
    const debtUSD = Number(totalDebtBase) / 1e8;
    const availableUSD = Number(availableBorrowsBase) / 1e8;
    const rawThreshold = Number(currentLiquidationThreshold) / 10000; // fraction, e.g. 0.825
    const ltvPct = Number(ltv) / 10000;
    const hf = Number(ethers.formatUnits(healthFactor, 18));

    let finalCollateralUSD = collateralUSD;
    let finalDebtUSD = debtUSD;
    let finalHF = hf;
    const finalThreshold = rawThreshold > 0 ? rawThreshold * 100 : 82.5;
    const finalLtv = ltvPct > 0 ? ltvPct * 100 : 75.0;

    if (finalDebtUSD === 0 || finalHF > 100 || !isFinite(finalHF)) {
      // When a wallet has $0 debt, health factor is infinite / not applicable
      finalHF = 0;
    }

    // Distance to liquidation: percentage fall in collateral before HF hits 1.0
    // HF = (Collateral * LiqThreshold) / Debt
    const distanceToLiquidation =
      finalCollateralUSD > 0 && finalDebtUSD > 0
        ? Math.max(0, (1 - (finalDebtUSD / (finalCollateralUSD * (finalThreshold / 100)))) * 100)
        : 100;

    return {
      totalCollateralUSD: finalCollateralUSD,
      totalDebtUSD: finalDebtUSD,
      availableBorrowsUSD: availableUSD,
      currentLiquidationThreshold: finalThreshold,
      ltv: finalLtv,
      healthFactor: finalHF,
      isAtRisk: finalDebtUSD > 0 && finalHF < 1.3,
      distanceToLiquidationPct: distanceToLiquidation,
    };
  } catch {
    // Graceful fallback when wallet is unindexed or RPC call fails
    return {
      totalCollateralUSD: 0,
      totalDebtUSD: 0,
      availableBorrowsUSD: 0,
      currentLiquidationThreshold: 0,
      ltv: 0,
      healthFactor: 0,
      isAtRisk: false,
      distanceToLiquidationPct: 100,
    };
  }
}

/**
 * Calculates debt reduction needed to reach a target health factor
 */
export function calculateRequiredDebtRepayment(
  totalCollateralUSD: number,
  currentDebtUSD: number,
  liquidationThresholdPct: number,
  targetHF: number = 2.0
): number {
  if (currentDebtUSD <= 0) return 0;
  const thresholdFraction = liquidationThresholdPct > 1 ? liquidationThresholdPct / 100 : liquidationThresholdPct;
  const maxAllowedDebt = (totalCollateralUSD * thresholdFraction) / targetHF;
  if (currentDebtUSD <= maxAllowedDebt) return 0;
  return Math.max(0, currentDebtUSD - maxAllowedDebt);
}

/**

export function toPositionSnapshot(

  data: UserAccountData,
  protocol: string = 'aave-v3'

    data.totalDebtUSD > 0 && isFinite(data.healthFactor) && data.healthFactor > 0 && data.healthFactor <= 100

      : '0.0000';
  return {

    healthFactor: safeHF,
    collateral: data.totalCollateralUSD.toFixed(2),
    debt: data.totalDebtUSD.toFixed(2),

  };

/**
 * Fetch real-time token USD price with caching and multi-source fallback
 */
export async function getTokenPriceUSD(symbol: string): Promise<number> {
  const sym = symbol.toUpperCase();
  const cached = priceCache.get(sym);
  if (cached && Date.now() - cached.timestamp < CACHE_TTL_MS) {
    return cached.priceUSD;
  }

  const coinId = COINGECKO_ID_MAP[sym];
  if (!coinId) {
    return FALLBACK_PRICES[sym] ?? (KNOWN_STABLECOINS.has(sym) ? 1.0 : 0);
  }

  try {
    // Attempt 1: CoinGecko Simple Price API
    const controller = new AbortController();
    const timeoutId = setTimeout(() => controller.abort(), 3000);
    
    const res = await fetch(
      `https://api.coingecko.com/api/v3/simple/price?ids=${coinId}&vs_currencies=usd`,
      { signal: controller.signal }
    );
    clearTimeout(timeoutId);

    if (res.ok) {
      const data = (await res.json()) as Record<string, { usd: number }>;
      if (data[coinId]?.usd) {
        const price = data[coinId].usd;
        priceCache.set(sym, { priceUSD: price, timestamp: Date.now() });
        return price;
      }
    }
  } catch {
    // API failed or timed out, attempt secondary fallback
  }

  try {
    // Attempt 2: DeFiLlama Coin Price API
    const controller = new AbortController();
    const timeoutId = setTimeout(() => controller.abort(), 3000);

    const res = await fetch(
      `https://coins.llama.fi/prices/current/coingecko:${coinId}`,
      { signal: controller.signal }
    );
    clearTimeout(timeoutId);

    if (res.ok) {
      const data = (await res.json()) as { coins?: Record<string, { price: number }> };
      const key = `coingecko:${coinId}`;
      if (data.coins?.[key]?.price) {
        const price = data.coins[key].price;
        priceCache.set(sym, { priceUSD: price, timestamp: Date.now() });
        return price;
      }
    }
  } catch {
    // Fallback to static reference table
  }

  const fallback = FALLBACK_PRICES[sym] ?? (KNOWN_STABLECOINS.has(sym) ? 1.0 : 0);
  priceCache.set(sym, { priceUSD: fallback, timestamp: Date.now() });
  return fallback;
}

/**
 * Resilient JSON-RPC Provider Failover
 * Attempts queries through ordered pool of public and private RPC endpoints
 */
export async function withResilientProvider<T>(
  chain: keyof typeof SUPPORTED_CHAINS = 'ethereum',
  callback: (provider: ethers.JsonRpcProvider) => Promise<T>
): Promise<T> {
  const config = SUPPORTED_CHAINS[chain] || SUPPORTED_CHAINS.ethereum;
  const urls = config.rpcUrls;

  let lastError: any = null;

  for (const url of urls) {
    try {
      const provider = new ethers.JsonRpcProvider(url, undefined, {
        staticNetwork: ethers.Network.from(config.chainId),
      });

      // Quick liveness test or direct callback execution
      const result = await callback(provider);
      return result;
    } catch (err) {
      lastError = err;
      console.warn(`[rpcTools] RPC ${url} failed on ${config.name}, falling back to next...`);
    }
  }

  throw new Error(
    `All RPC providers exhausted for chain ${String(chain)}. Last error: ${String(lastError?.message || lastError)}`
  );
}

 * Get active provider for chain
 */
export function getProvider(chain: keyof typeof SUPPORTED_CHAINS = 'ethereum'): ethers.JsonRpcProvider {

export async function callQwenLLM(prompt: string, retries: number = 1): Promise<string> {
  const baseUrl = process.env.QWEN_API_URL;
  if (!baseUrl) {
    throw new Error("QWEN_API_URL not configured");
  }

  const timeout = 2500;

  for (let attempt = 0; attempt < retries; attempt++) {
    try {
      const controller = new AbortController();
      const timeoutId = setTimeout(() => controller.abort(), timeout);

      const endpoint = baseUrl.endsWith("/api/generate") ? baseUrl : `${baseUrl.replace(/\/$/, "")}/api/generate`;

      const res = await fetch(endpoint, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          model: "qwen2.5:0.5b",
          prompt,
          stream: false,
          temperature: 0.3,
          top_p: 0.8
        }),
        signal: controller.signal
      });

      clearTimeout(timeoutId);

      if (!res.ok) {
        throw new Error(`HTTP ${res.status}`);
      }

      const data = await res.json();

      if (typeof data.response === "string" && data.response.trim().length > 0) {
        return data.response;
      }
      if (data.message?.content && typeof data.message.content === "string" && data.message.content.trim().length > 0) {
        return data.message.content;
      }
      if (typeof data === "string" && data.trim().length > 0) {
        return data;
      }

      throw new Error("Empty response from LLM");
    } catch (error) {
      const isLastAttempt = attempt === retries - 1;
      const errorMsg = error instanceof Error ? error.message : String(error);
      console.warn(`[Qwen LLM] Attempt ${attempt + 1}/${retries} failed: ${errorMsg}`);

      if (isLastAttempt) {
        throw new Error(`LLM call failed after ${retries} attempts: ${errorMsg}`);
      }

      // Exponential backoff before retry
      await new Promise((resolve) => setTimeout(resolve, 1000 * Math.pow(2, attempt)));
    }
  }

  throw new Error("LLM call exhausted all retries");
}

/**
 * Safe JSON extraction from LLM response
 * Handles markdown, extra text, and various formats
 */
export function extractJSON<T = any>(text: string): T {
  if (!text || typeof text !== "string") {
    throw new Error("Invalid input: expected string");
  }

  const cleaned = text
    .replace(/```json\n?/g, "")
    .replace(/```\n?/g, "")
    .trim();

  // Try to find JSON object by brackets
  let jsonStr = "";
  let depth = 0;
  let startIdx = -1;

  for (let i = 0; i < cleaned.length; i++) {
    const char = cleaned[i];

    if (char === "{") {
      if (depth === 0) startIdx = i;
      depth++;
    } else if (char === "}") {
      depth--;
      if (depth === 0 && startIdx !== -1) {
        jsonStr = cleaned.slice(startIdx, i + 1);
        break;
      }
    }
  }

  if (!jsonStr) {
    throw new Error(`No valid JSON object found in response: "${cleaned.substring(0, 100)}..."`);
  }

  try {
    return JSON.parse(jsonStr) as T;
  } catch (e) {
    throw new Error(`Failed to parse JSON: ${e instanceof Error ? e.message : String(e)}`);
  }
}

    const risk = await assessRisk(address, hf);
    if (risk.score < 20) return;

    await recommendAction(snapshot);
    const confidence = risk.source === 'deterministic' ? 0.8 : 0.6;
    const decision = await evaluateAlert(address, hf, confidence);
    if (!decision.allowed) {
        console.log(`[scanPositionWorkflow] Alert rejected: ${decision.reason}`);
        return;
    }
    alertCorrelator.ingestLiquidationAlert(snapshot);
    console.log(`[scanPositionWorkflow] Alert emitted for ${key}, HF: ${hf}, tier: ${risk.tier}`);
}

export async function runScanLoop(): Promise<void> {
    const entry = dequeueNext();
    if (!entry) return;
    await processPosition(entry.address);
}

export function getWalletProfile(address: string): WalletProfile | undefined {
    return walletProfiles.get(address.toLowerCase());
}

export function startWorkflow(intervalMs = 1000): () => void {
    console.log(`[scanPositionWorkflow] LiquidShield workflow started (poll every ${intervalMs}ms)`);
    let isRunning = true;
    async function loop() {
        if (!isRunning) return;
        try {
            await runScanLoop();
        } catch (err) {
            console.error('[scanPositionWorkflow] Pipeline error:', err);
        } finally {
            if (isRunning) {
                setTimeout(loop, intervalMs);
            }
        }
    }
    loop();
    return () => { isRunning = false; };
}

import type { WhaleScanResult, WalletProfile } from '../types.ts';
import { startScanner, onLargeTransaction } from '../agents/scannerAgent.ts';
import { classifyIntent } from '../agents/intentAgent.ts';
import { formatAlert, routeToCorrelator } from '../agents/alertAgent.ts';
import { evaluateAlert } from '../agents/wwGovernanceAgent.ts';
import * as walletHistory from '../memory/walletHistory.ts';

const registeredWallets = new Set<string>();
const walletProfiles = new Map<string, WalletProfile>();

export async function registerWallet(address: string): Promise<void> {
    const key = address.toLowerCase();
    if (registeredWallets.has(key)) return;
    registeredWallets.add(key);
    walletProfiles.set(key, { address: key });
    
    // Persist to local DB shim if not already there
    import('../index.ts').then(async ({ prisma }) => {
        const existing = await prisma.wallet.findMany();
        if (!existing.some((w: any) => w.address.toLowerCase() === key)) {
            await prisma.wallet.create({ data: { address: key, type: 'WHALE' } });
            console.log(`[watchWalletWorkflow] Persisted ${key} to local_db.json`);
        }
    });

    await walletHistory.backfill(address);
    console.log(`[watchWalletWorkflow] Wallet registered and backfilled: ${key}`);
}

export async function processTransaction(scan: WhaleScanResult): Promise<void> {
    const addr = scan.address.toLowerCase();
    // Only process transactions for explicitly registered surveillance targets
    if (!registeredWallets.has(addr)) {
        return;
    }
    await walletHistory.append(scan.address, scan);
    const intentResult = await classifyIntent(scan.address);
    const alert = await formatAlert(scan, intentResult.intent, intentResult.label);
    if (!alert) return;
    const confidence = intentResult.source === 'local' ? 0.9 : 0.75;
    const decision = await evaluateAlert(scan.address, confidence);
    if (!decision.allowed) {
        console.log(`[watchWalletWorkflow] Alert rejected: ${decision.reason}`);
        return;
    }
    const enrichedScan: WhaleScanResult = {
        ...scan,
        intent: intentResult.intent,
        label: intentResult.label || scan.label,
    };
    await routeToCorrelator(alert);
    const profile = walletProfiles.get(addr);
    if (profile) {
        profile.lastWWSnapshot = enrichedScan;
        walletProfiles.set(addr, profile);
    }
    console.log(`[watchWalletWorkflow] Alert processed: ${scan.txHash} (${intentResult.intent})`);
}

export function getWalletProfile(address: string): WalletProfile | undefined {
    return walletProfiles.get(address.toLowerCase());
}

export function startWorkflow(): void {
    onLargeTransaction((scan) => {
        processTransaction(scan).catch((err) => {
            console.error('[watchWalletWorkflow] Pipeline error:', err);
        });
    });
    startScanner();
}

import fs from 'node:fs';
import path from 'node:path';
import { execSync } from 'node:child_process';

const ROOT_DIR = process.cwd();
const OUTPUT_FILE = path.join(ROOT_DIR, 'chain-sentinel-codebase.txt');

// Binary / large auto-generated files to skip
const IGNORED_FILES = new Set([
  'pnpm-lock.yaml',
  'chain-sentinel-codebase.txt',
  'apps/web/public/favicon.ico',
  'apps/web/public/logo-new.png',
  'apps/web/public/logo.png',
  'apps/web/public/logo1.png',
  'apps/web/src/app/favicon.ico',
]);

const IGNORED_EXTENSIONS = new Set([
  '.ico',
  '.png',
  '.jpg',
  '.jpeg',
  '.svg',
  '.gif',
  '.webp',
  '.woff',
  '.woff2',
  '.ttf',
  '.eot',
  '.lock',
]);

function getTrackedFiles(): string[] {
  const output = execSync('git ls-files', { encoding: 'utf-8' });
  return output
    .split(/\r?\n/)
    .map((f) => f.trim())
    .filter((f) => f.length > 0 && !IGNORED_FILES.has(f) && !IGNORED_EXTENSIONS.has(path.extname(f).toLowerCase()));
}

function run() {
  console.log('Gathering codebase files for Notebook export...');
  const files = getTrackedFiles();
  console.log(`Found ${files.length} source and documentation files.`);

  const chunks: string[] = [];

  chunks.push('================================================================================');
  chunks.push('CHAIN SENTINEL - FULL CODEBASE & SPECIFICATIONS EXPORT');
  chunks.push(`Generated: ${new Date().toISOString()}`);
  chunks.push('Repository: https://github.com/vismaygawai/chain.sentinel');
  chunks.push('Live Web Dashboard: https://chain-sentinel-web.vercel.app/');
  chunks.push('Live API Service: https://chain-sentinel.onrender.com/');
  chunks.push('Team: WWHS? | Hackathon: ELECTROTHON 8.0');
  chunks.push('================================================================================\n');

  chunks.push('TABLE OF CONTENTS & FILE INDEX:');
  chunks.push('--------------------------------------------------------------------------------');
  files.forEach((file, idx) => {
    chunks.push(`${(idx + 1).toString().padStart(3, ' ')}. ${file}`);
  });
  chunks.push('--------------------------------------------------------------------------------\n\n');

  let totalLines = 0;

  for (const relativePath of files) {
    const fullPath = path.join(ROOT_DIR, relativePath);
    if (!fs.existsSync(fullPath)) continue;

    try {
      const content = fs.readFileSync(fullPath, 'utf-8');
      const lines = content.split(/\r?\n/).length;
      totalLines += lines;

      chunks.push('================================================================================');
      chunks.push(`FILE: ${relativePath} (${lines} lines)`);
      chunks.push('================================================================================');
      chunks.push(content);
      chunks.push('\n');
    } catch (err) {
      console.warn(`Could not read file: ${relativePath}`, err);
    }
  }

  const result = chunks.join('\n');
  fs.writeFileSync(OUTPUT_FILE, result, 'utf-8');

  const stats = fs.statSync(OUTPUT_FILE);
  const sizeKb = (stats.size / 1024).toFixed(2);
  console.log(`\nSuccessfully exported full codebase to: ${OUTPUT_FILE}`);
  console.log(`Total files: ${files.length}`);
  console.log(`Total lines of code/docs: ${totalLines}`);
  console.log(`Total file size: ${sizeKb} KB`);
}

run();
